# 端侧离线工作搭子 · 操作手册

> 适用版本：v1.0 ｜ 运行模式：全程离线 · 本地推理

**端侧离线工作搭子** 是一款把语音识别、机器翻译、语音合成与大语言模型全部装进手机的离线智能助手。
所有音视频、文本与生成结果都在本机处理，**不联网、不出手机**。

APP 内置 8 个智能体，**全部可点击进入使用**：**文本对话**、**语音通话**、**录音翻译**、**本地视频字幕**、**跨语沟通**、**实时视频听音**（Beta）、**全能扫描**、**文档识别翻译**。本手册逐章说明各智能体的用法。

## 第一章 开始之前

### 1.1 首页

打开 APP 进入首页，自上而下依次是：

| 区域 | 说明 |
| --- | --- |
| 应用栏 | 左侧 Logo 与「端侧离线工作搭子」，右侧齿轮图标进入**设置** |
| 智能体小卡片 | 6 张小卡片（图标 + 名称 + 标签），点击直接进入对应功能页；开始对话后折叠成一条横向滑动条 |
| 模式切换 | 「文本对话 / 语音通话」分段控件，两者共用同一个对话框，不跳转页面 |
| 对话区 | 文本模式下是消息气泡 / 空态推荐问题；通话模式下是通话状态与逐条转写 |
| 底部输入 | 文本模式为输入框（回形针可上传文档）；通话模式为音色选择与通话 / 挂断按钮 |

**文本对话**与**语音通话**已融合在首页对话框里，不再单独进二级页：切换模式前会把另一路停下
（麦克风与模型推理同时只能服务一路），因此不用担心两者互相打断。

卡片上的 Beta 标记（实时视频听音）表示功能可用但仍在优化；待上线标记的暂不可点击。

### 1.2 设置页

首页右上角齿轮进入设置，共三组：

**外观**——主题模式三选一，切换即时生效：

- 浅色
- 深色
- 跟随系统（跟随手机的深浅色设置自动切换）

**推理**——NPU 加速（NNAPI）开关：

- 开启后用手机 NPU 加速推理，可能更快，但兼容性因机型而异；
- 切换后会自动重载模型；
- 若开启后出现**翻译变慢、出错或乱码**，说明该机型 NPU 不支持当前算子，**关掉即可**。

**关于**——应用名称「端侧离线工作搭子」、版本 v1.0、运行模式「全程离线 · 本地推理」。

### 1.3 首次使用须知

1. **系统权限**：录音翻译与跨语沟通需要**麦克风**权限；上传音频/视频、导出生成文件需要**存储访问**权限。首次点击相关按钮时系统会弹窗申请。
2. **模型加载**：端侧模型在首次使用时加载到内存，页面会显示「模型加载中…」；模型较大时请耐心等待，加载完成后才进入识别。
3. **保持前台**：APP 在前台时不熄屏（已开启屏幕常亮），长视频字幕生成、长时间录音过程中请勿切到后台。
4. **离线**：全程不需要网络，飞行模式下同样可用，所有推理都在本地完成。

## 第二章 录音翻译智能体

> 会议、对话场景下实时录音并转写翻译，全程离线，隐私无忧。

### 2.1 能做什么

- **实时录音转写**：边说边出文字，按语音停顿自动分段。
- **离线翻译**：转写同时译成目标语种，逐段呈现原文与译文。
- **上传音频**：除麦克风录音外，可选择本地音频文件整条识别（自动切段）。
- **AI 纪要整理**：一条录音一键整理成结构化会议纪要（话题 + 要点 + 待办）。
- **历史与导出**：每次录音自动存档，可回看、整理纪要、导出音频或文本、删除。

### 2.2 界面速览

页面顶部是橙色标题栏「录音翻译智能体」，右侧三个操作块：

| 操作块 | 作用 |
| --- | --- |
| **配置** | 展开/收起配置抽屉（音频输入、语音语种、翻译开关与目标语种） |
| **历史** | 展开/收起历史抽屉，角标显示已保存的条数 |
| **录音 / 停止 / 上传** | 主操作块，随状态变化：待机显示「录音」，录音中显示「停止」，停止后排空识别时显示「识别中」（禁用转圈）；上传音频模式下显示「上传」 |

主区是「实时结果」卡片，逐段展示转写与译文，新结果自动滚动到最新一条。

### 2.3 配置

点「配置」展开抽屉，共三项：

1. **音频输入**：`录音` / `上传音频` 二选一。
2. **语音语种**：默认「自动识别」；若录音很短或环境嘈杂，可**指定具体语种**让识别更稳（30 种语种 + 22 种中国方言）。
3. **翻译**：开关 + 目标语种（50 种）。关闭时只做转写，不做翻译。
   - 当源语种不支持翻译、或目标语种与源语种相同时，开关置灰并显示原因（换一个目标语种即可解除）。

> 配置抽屉在录音/识别进行中不可修改（自动禁用）。

### 2.4 标准流程：录音翻译

1. 点「配置」，设置**音频输入 = 录音**、**语音语种**（自动识别或指定）、打开**翻译**并选择**目标语种**。
2. 点右上角「**录音**」（首次会申请麦克风权限）。
3. 状态栏显示「模型加载中…」，就绪后变为「正在录音…」。
4. 说话过程中已识别的段落陆续出现在结果区，状态显示「识别中…(段 N)」。
5. 说完后点「**停止**」。此时主操作块变为「识别中」，等待剩余音频排空识别。
6. 完成后状态显示「已完成 · 共 N 段」，该条记录自动存入**历史**。

**结果卡片**包含：时间标签、「转写」原文、以及（开启翻译时的）「译文」。每段左侧有圆形播放按钮，可回放该段**原音**；同一时刻只播放一段。

### 2.5 上传音频识别

1. 「配置」中把**音频输入**切到 `上传音频`。
2. 点右上角「**上传**」，在系统文件选择器中挑选音频文件（`audio/*`）。
3. 结果区顶部会钉住一条**整条音频预览卡**：文件名、时长、大小 + 整条播放按钮，可先试听原文件。
4. 系统自动切段识别，下方逐段显示「转写 / 译文」与切分进度。
5. 完成后同样进入历史记录。

> 提示：上传的是音频文件本体，长音频会先扫描整条估音量、再切段识别，耗时比实时录音略长。

### 2.6 历史记录

点「历史」展开抽屉（最多占屏幕一半高度，不会遮住结果区）：

- 每条记录显示**标题**（已有纪要时取 AI 提炼出的会议主题，否则取首段转写）、时间、段数、译文语种、纪要标记；
- 右侧两个图标：**下载**、**删除**；
- 点击条目 → 结果区切换为「查看历史 · 时间」，右上角出现「**返回实时**」。

进入历史详情后，结果区顶部出现两个标签页与一行操作按钮：

| 控件 | 说明 |
| --- | --- |
| 标签页「**查看历史**」 | 该条录音的分段转写 / 译文，可回放原音 |
| 标签页「**纪要总结**」 | AI 整理出的会议纪要 |
| 「**整理纪要**」/「**重新整理纪要**」 | 生成或重新生成纪要；生成中变为「**停止生成**」 |
| 下载图标 | 弹出「选择下载内容」对话框 |
| 删除图标 | 删除该条记录 |

### 2.7 AI 纪要整理

在历史详情中点「**整理纪要**」，端侧大模型会把这条录音整理成结构化纪要：

- 生成中：先出现「**话题：**…」大纲（模型的话题梳理过程），随后正文逐字流出，待办单独成栏，下方附**关键句摘录**便于核对事实来源；状态提示为「纪要生成中…已梳理 i/n 段」。
- 完成后：纪要随记录保存，状态显示「纪要已生成」，可随时重新整理。
- 若已生成过，按钮变为「**重新整理纪要**」。
- 首次使用会先加载纪要模型，页面显示「纪要模型加载中…」。

### 2.8 导出与下载

历史条目（或历史详情）点**下载**图标 → 弹出「选择下载内容」：

| 选项 | 内容 | 文件格式 |
| --- | --- | --- |
| 完整音频 | 各段拼接的整条录音 | `.wav` |
| 源语言文本 | 仅转写原文 | `.txt` |
| 目标语言文本 | 仅译文 | `.txt` |
| 原译对照 | 转写 + 翻译对照 | `.txt` |
| 纪要总结 | AI 整理的会议纪要 | `.txt` |

选择后调起系统「保存文件」对话框，自行选择保存位置。没有音频（上传音频模式）时「完整音频」标注「无音频」不可选；未生成纪要时「纪要总结」标注「未生成」不可选。

## 第三章 本地视频字幕智能体

> 为本地视频自动生成字幕和总结，沉浸式字幕体验，快速视频内容总结查看。

### 3.1 能做什么

- **导入本地视频**：从手机存储选择视频文件导入 APP。
- **自动生成字幕**：抽取音轨 → 语音识别 → 可选翻译，得到带时间轴的双语字幕。
- **烧录字幕视频**：把字幕烧录进画面，生成可直接播放/分享的新视频。
- **AI 视频总结**：不看视频也能一眼了解内容（话题 + 要点 + 待办 + 关键句摘录）。
- **导出**：烧录好的结果视频可保存到手机任意位置。

### 3.2 相册页（入口页）

进入智能体后首先是相册页，右上角是「**上传**」操作块。

- 空状态提示：「还没有视频 / 点击右上角「上传」开始生成字幕」。
- 点「上传」→ 调起**系统文件选择器**（选择 `video/*` 视频文件）→ 自动导入（拷贝并生成缩略图）→ **自动进入任务页**。
- 已有视频以两列网格展示卡片：缩略图（带时长角标与状态角标）、名称、日期/语种。
- 点卡片进入该视频的**任务页**；卡片右上角可**删除**（确认对话框会提示：将删除该视频及其字幕、结果视频和总结，无法恢复）。
- 导入中或后台仍有任务在生成时，「上传」按钮置灰。

### 3.3 任务页

顶部标题为「本地视频字幕智能体」，副标题是视频名；返回键回到相册页。页面自上而下三块：

#### ① 原视频

可直接播放的原视频预览（点击画面唤出进度条）。

#### ② 目标语种与生成

| 控件 | 说明 |
| --- | --- |
| 语音语种 | 默认「自动识别」，也可指定具体语种（30 种 + 22 种方言）让识别更稳 |
| 翻译 开关 | 打开后字幕同时给出译文；源语种不支持翻译或与源语种相同时开关置灰并给出原因 |
| 目标语种 | 打开翻译后可选，共 50 种 |
| 「**生成字幕**」/「**重新生成**」 | 完成一次后按钮变为「重新生成」；生成中按钮显示状态与转圈 |
| 进度条 / 状态文字 | 烧录阶段显示百分比进度条，其余阶段显示状态文字 |

#### ③ 三个标签页（可左右滑动切换）

| 标签页 | 内容 |
| --- | --- |
| **分段字幕** | 按时间轴列出字幕：时间标签 +「转写」+「译文」，新字幕自动滚到底；未生成时提示「暂无字幕，点击「生成字幕」开始」 |
| **字幕视频** | 烧录好字幕的结果视频，自动循环播放；下方「**下载视频**」保存到系统目录。未完成时提示「字幕生成完成后，烧录好字幕的视频将在这里展示」，烧录中显示「烧录字幕中…x%」 |
| **视频总结** | 「**生成总结**」/「**重新总结**」按钮 +「**停止生成**」；空态提示「AI 视频总结：不看视频，一眼了解视频内容」 |

视频总结的展示形式与纪要一致：生成中先出「**话题：**…」大纲，再流式出正文，待办单独成栏，末尾附关键句摘录；生成完成后整篇随任务保存。

### 3.4 处理阶段与状态提示

生成过程中，按钮旁的状态文字会依次变化，便于判断进度：

1. `导入视频中…`（上传阶段）
2. `提取音频中…`
3. `分析音量…`
4. `识别中…` / `识别中…(段 N)`
5. `翻译中…(段 N)`（开启翻译时）
6. `烧录字幕中…` → `烧录字幕中…x%`（带进度条）
7. `字幕生成完成`

总结阶段另有 `总结中…已梳理 i/n 段` → `视频总结已生成`。

出错时状态文字与错误详情以红色显示（例如字幕过长导致内存不足时，会提示缩短字幕文本或分段后再试）。

### 3.5 使用建议

- **长视频**：时长越长，识别与烧录耗时越久，请保持 APP 在前台（已开启屏幕常亮）。
- **源语种**：语音语种不确定时先选「自动识别」；若识别语种明显错误，改为指定语种重新生成。
- **只要字幕不要翻译**：关掉「翻译」开关再生成，速度更快。
- **重新生成**：调整语种或翻译开关后点「重新生成」，会覆盖上一次的字幕与结果视频。

## 第四章 跨语沟通智能体

> 多人多语实时沟通：按说话人转写并译成对方语言，双色分区展示，全程离线。

### 4.1 能做什么

- **双方各说各的语言**：A 说中文、B 说英文，APP 自动判定「这轮是谁在说」。
- **自动译成对方语种**：A 的中文译成英文给 B 听，B 的英文译成中文给 A 听。
- **音色克隆播报**：译文用说话人自己的音色合成并自动播报，对方听到的是「你的声音在说他的语言」。
- **双色分区展示**：两人的发言用不同颜色卡片区分，卡片内含原音、转写、译文、播报。
- **历史与双语纪要**：整场沟通自动存档，事后可针对**某一条历史记录**生成 A / B 两个语种各一份的纪要。

### 4.2 配置沟通双方

点头部「**配置**」展开「沟通双方配置」：

- 两张卡片分别是 A 方与 B 方（卡片颜色对应发言流中的配色）；
- 每方可设置：**昵称**（最多 8 个字）与**语种**（19 种）；
- 点语种行弹出「XXX 的语种」选择框。

配置区底部说明：**谁在说话由语音自动判定；译文自动译成对方语种；播报用说话人自己的音色合成（克隆自本段语音），19 种语种均支持。**

> 配置仅在待机（未录音/未处理）状态下可修改。

### 4.3 界面速览

头部三个操作块：**配置** / **历史** / 主操作。主操作随状态变化：

| 状态 | 主操作块 |
| --- | --- |
| 待机 | 「**开始**」 |
| 录音中 | 「**停止**」 |
| 处理中 | 「**处理中**」（禁用转圈） |
| 播报中 | 「**播报中**」（禁用） |

主区自上而下：

1. **状态条**：录音中显示红点与「录音中 x.xs · 说完点「停止」」；其余状态显示处理进度或「点「开始」说话，自动识别语种并译给对方」，右侧显示双方昵称与语种速览。
2. **错误提示条**（有错误时）：红色条显示原因，右侧 ✕ 可清除。
3. **发言流**：尚未开始时提示「配置好双方语种后点「开始」：谁在说话由语音自动判定，译文按对方语种合成播报」。

### 4.4 一轮对话的完整流程

1. 配置好 A / B 双方的昵称与语种。
2. A 点「**开始**」说话（首次需麦克风权限），说完点「**停止**」。
3. 卡片依次经历：`转写中…` → `翻译中…` → `语音合成中…N 帧` → `播报中`，自动播报译文给对方听。
4. 把手机递给 B，B 点「**开始**」说下一段，如此往复。

**发言卡片**内容自上而下：

| 元素 | 说明 |
| --- | --- |
| 说话人 + 语种方向 | 如「张总 · 中文 → 英语」，未判定时显示「识别语种中…」 |
| 原音 | 圆形播放按钮 +「原音」标签，可回放这一轮的真实录音 |
| 转写 | 该轮语音识别出的原文 |
| 译文 | 译成对方语种的文本 |
| 播报 | 播放按钮 +「播报」标签 + 目标语种，可重听合成语音 |
| 阶段徽标 | 转写中 / 翻译中 / 语音合成中 / 播报中 / 处理失败 |

> 原音与播报共用一个播放器：同一时刻只播放一个，点新的会停掉旧的，也会停掉正在进行的自动播报。

### 4.5 历史记录

点头部「**历史**」进入历史面板：

- 列出历次沟通会话，每条显示名称/时间/段数等信息；
- 每行右侧的**纪要图标**：点击可**直达该会话的双语纪要页**；图标旁显示已生成的纪要进度（如「纪要 1/2」）；
- 点击条目本身 → 展开该会话；点左上角返回箭头或删除按钮可回到列表（删除会二次确认）。

#### 展开会话后的两个标签页

| 标签页 | 内容 |
| --- | --- |
| **会话详情** | 这场沟通的逐条发言卡片，可回放原音与播报 |
| **双语纪要** | 针对**这条历史记录**生成的纪要，分 A / B 两个语种 |

### 4.6 双语纪要

纪要**只针对这条历史记录里记录下来的沟通内容**，与当前是否正在录音无关。

**语种 Tab**：顶部两个 Tab 分别是 A 方语种与 B 方语种的纪要（如「中文纪要」「英语纪要」），各自独立、互不覆盖。

**操作区**（固定两行，不随生成状态变形）：

| 控件 | 说明 |
| --- | --- |
| 「**双语纪要**」 | 依次生成 A、B 两个语种各一份纪要 |
| 「**停止**」 | 常驻按钮，非生成期置灰；生成中点击可中止 |
| 单语按钮 ×2 | 第二行两个按钮，只生成对应语种的那一份（如「中文」「英语」） |

生成中，正文上方有一行进度提示（如「正在整理英语纪要…」「正在加载纪要模型…」）。

**纪要内容**：沿用「话题 → 要点 → 待办」三段结构，生成中三块内容各自流式增长，末尾附关键句摘录；每个语种下的纪要**全部使用该语种书写**。

**注意事项**：

- 某语种下没有可用文本（例如对方的译文缺失）时，该语种纪要会跳过，不会产出语种不符的内容；
- **关闭历史面板**会停掉正在进行的纪要生成；
- 仅切到「会话详情」标签页**不会**中断生成，切回「双语纪要」进度仍在；
- 纪要随会话保存，重新打开历史即可看到，可再次生成覆盖。

## 第五章 文本对话与语音通话智能体

### 5.1 文本对话智能体

- **核心功能**：以**文字交互**的形式提供端侧大模型问答服务。
- **两种推理模式**（页面顶部切换）：
  - `不思考`：直接输出正文，响应快，适合闲聊与简单问答；
  - `深度思考`：模型先展开推理链再作答，气泡内可实时看到灰色的「思考过程」区块，适合推理、计算与复杂问题。
- **上传文档问答**：点「上传文档用于问答」选择 `txt` / `Word(.docx)` / `PDF` / 图片；识别完成后顶部显示文档名与字数，
  此后每次提问都会自动从全文里检索与问题最相关的段落送进模型，回答优先依据文档内容。
- 输入框右侧按钮在生成中变为**停止**，可随时中断；「清空」新建会话（已上传文档保留，便于连续追问）。

### 5.2 语音通话智能体

- **核心功能**：以**通话形式**进行**纯语音交互**——不用打字，像打电话一样直接说话。
- **使用流程**：点绿色「开始通话」→ 授权麦克风 → 说完一句话后**停顿约 0.6 秒**即被识别 → 页面依次显示
  「识别中 / 思考中 / 正在说话」，回答以语音播出 → 听完后继续说下一句。
- **半双工**：智能体说话时不会采集你的声音（避免把自己的外放声听进去），请等它说完再开口。
- **音色**：底部可切换内置音色（中 / 英 / 日男女声）；首次通话需要加载语音合成模型，加载完成前的回复先以文字呈现。
- 红色按钮「挂断」结束通话并释放录音。

### 5.3 实时视频听音智能体（Beta）

- **核心功能**：实时听音**悬浮字幕**——播放音视频的同时，在悬浮窗口里实时显示字幕。
- **语种**：支持 50 种语言。
- **状态**：Beta 版，当前效率较低，**正在升级中**。

### 5.4 全能扫描智能体

- **核心功能**：**拍照扫描各类格式的扫描件**——拍照后自动识别文档区域并生成高清扫描件。

### 5.5 文档识别翻译智能体

- **核心功能**：离线**识别各类文档并翻译**，支持**格式还原导出**。
  - 支持格式：`txt` / `Word(.docx)` / `PDF`（文字版与扫描件）/ 图片；
  - 两种模式：`翻译`（文字版 PDF / docx / txt 直接抽取文字后翻译）、`OCR+翻译`（PDF 逐页或图片 OCR 后翻译，也可只做 OCR 不翻译）；
  - 导出格式：`txt` / `word` / `pdf`。

## 第六章 通用设置与注意事项

### 6.1 权限

| 权限 | 用途 | 触发时机 |
| --- | --- | --- |
| 麦克风 | 录音翻译实时录音、跨语沟通采集发言 | 首次点「录音」/「开始」 |
| 存储访问 | 上传音频/视频、导出音频与视频、保存文本 | 首次上传或导出 |

### 6.2 性能与稳定性

- **首次加载模型较慢**：识别、翻译、纪要三类模型都是首次使用时按需加载，页面会明确提示「模型加载中…」。
- **长内容耗时**：长音频/长视频的识别与烧录是分钟级操作，请保持 APP 前台运行（已开启屏幕常亮）。
- **内存**：视频字幕过长可能触发内存不足提示，可缩短内容或分段处理。
- **NPU 加速**：设置页可开关；出现变慢、出错或乱码时关闭即可。

### 6.3 数据与隐私

- 全部计算在本机完成，**无需联网**，录音、视频、文档与生成结果均保存在手机本地；
- 删除历史记录、删除视频会连同字幕、结果视频与总结一并清除，操作前会二次确认。

### 6.4 常见问题

| 现象 | 处理 |
| --- | --- |
| 点「录音」没反应 | 检查是否已授予麦克风权限 |
| 上传音频/视频没反应 | 用系统文件选择器重新选择；确认文件未损坏、时长未过长 |
| 翻译开关置灰 | 源语种不支持翻译，或目标语种与源语种相同；页面会给出原因，换一个目标语种即可 |
| 识别语种不对 | 把「语音语种」从「自动识别」改为指定语种后重新生成 |
| 纪要/总结为空 | 端侧模型偶发空输出，点「重新整理纪要」/「重新总结」再试一次 |
| 开启 NPU 后乱码 | 设置页关闭「NPU 加速（NNAPI）」，模型会自动重载 |
